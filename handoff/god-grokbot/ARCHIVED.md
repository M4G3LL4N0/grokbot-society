# ARCHIVED — experimental God handoff

This package belongs to the **archived prototype** God GrokBot.

It is kept for reference only. The production contract is
[`../god-v2/`](../god-v2/), which is radically smaller and is the only package a
fresh God should be initialized from.

Do not use this package to create a God. Do not migrate this God.

Production package: `handoff/god-v2/`
- `GOD_PROMPT.txt` — the entire production prompt
- `SETUP.md` — three commands
- `CONTRACT.json` — the stable machine contract
- `HEALTHCHECK.md` — the 60-second check
- `OLD_GOD_MIGRATION.md` — how to import durable state, if any
